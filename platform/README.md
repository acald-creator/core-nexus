# Platform Components

This directory is reserved for implementation code and configuration as the architecture moves from documentation into concrete components.

- `soc/` for SOC services and integration code.
- `sensors/` for Suricata and runtime sensor integration.
- `ai-inference/` for AI triage and model orchestration.
- `mcp/` for the Nexus MCP server.
- `workbench/` for the operator and MLOps workbench.
- `athena/` for adversary emulation and fuzzer integration.
